# Security policy — training repository

This repository is for original personal learning code only. Do not upload enterprise credentials, customer files, proprietary source code, production endpoints, session URLs, or secrets.

Report sample-project security issues by opening a private communication channel with the repository owner; do not publish exploit details or credentials in public issues.

Use OIDC federation rather than stored Azure client secrets. Give deployment identities least-privilege permissions. Restrict production environment approvals where supported.
